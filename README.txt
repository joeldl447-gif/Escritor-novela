ESCRITOR — PWA

Esta versión está preparada para instalarse como aplicación desde Chrome en Android.

IMPORTANTE:
Una PWA necesita abrirse desde una dirección HTTPS para que Chrome permita la instalación completa.
El ZIP contiene todo lo necesario para publicarla.

Una vez publicada:
1. Abrí la dirección en Chrome.
2. Menú ⋮ > "Agregar a pantalla principal" / "Instalar aplicación".
3. Se creará el ícono "Escritor".
4. Podrá abrirse como una aplicación independiente.

Los documentos se guardan localmente en el navegador del teléfono.
