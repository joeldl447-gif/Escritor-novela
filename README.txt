V24 — LÍNEA TEMPORAL
- Detecta acontecimientos relevantes automáticamente.
- Detecta fechas y horas expresadas en el texto.
- Muestra personajes y lugares asociados a cada acontecimiento.
- Cada elemento lleva al párrafo original.
- Filtros: Todo / Con fecha-hora / Acontecimientos.
- No inventa fechas ni cronología cuando el texto no permite determinarla.
- Mantiene fichas V23, búsqueda, copias/historial e IA local segura.
