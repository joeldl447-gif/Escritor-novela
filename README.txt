V8 — ASISTENTE IA Y VOZ
- Conversación con IA desde el menú vertical.
- Entrada por voz mediante SpeechRecognition del navegador.
- Lectura en voz alta mediante speechSynthesis.
- Comandos locales para leer capítulos.
- Consultas sobre capítulos, personajes, lugares, notas y continuidad.
- Búsqueda local de fragmentos relevantes antes de enviar la consulta.
- Configuración local de clave de API y modelo.
- La clave se guarda en el dispositivo y NO se incluye en los archivos de GitHub.
- La llamada de IA usa la API de OpenAI Responses.
NOTA: la clave de API es un secreto y una app web no puede protegerla completamente. Para máxima seguridad conviene un servidor intermedio.
